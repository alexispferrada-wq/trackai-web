## 📌 Descripción del Repositorio

Repositorio público del frontend y punto de entrada web para **TrackAI** ([trackai.party](https://trackai.party)), el copiloto de mezcla con inteligencia artificial en tiempo real para DJs profesionales.

Aloja:
1. **Landing Page Oficial:** Presentación interactiva, capturas de cabina, demostración de funciones e integración de pagos.
2. **Servidor de Releases y Telemetría de Versiones:** Archivos JSON de actualización automática para el cliente Electron (`version.json`, `version-x.x.x.json`).
3. **Manual Oficial de Cabina:** Guía de uso en directo para DJs (`manual.html`).
4. **Brand Kits y Assets:** Recursos gráficos de marca para TrackAI y PRE-SET.

---

## 🚀 Ecosistema de Productos

- **TrackAI Desktop:** Copiloto con Live Pitch®, compatibilidad Camelot y lectura SQLite sombra para Serato DJ Pro, Virtual DJ y Rekordbox.
- **PRE-SET by TrackAI:** Arquitectura dataless 0 KB en macOS APFS para estructurar gig crates desde Google Drive sin duplicar gigabytes locales ([preset.trackai.party](https://preset.trackai.party)).
- **trackai-lib:** Librería Open Source de solo lectura para bases de datos de Serato DJ ([@alexispferrada-wq/trackai-lib](https://github.com/alexispferrada-wq/trackai-lib)).
